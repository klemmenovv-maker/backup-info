# backup-info

Information site and privacy policy for **Backup**, a personal macOS app that backs up photos (CR3, ARW and JPEG) from local folders, SSDs and memory cards to Google Drive.

The site is published with GitHub Pages: https://klemmenovv-maker.github.io/backup-info/

## Pages

- [`index.html`](index.html): what the app does
- [`privacy.html`](privacy.html): privacy policy, including Google API data use

## Contact

Open a [GitHub issue](https://github.com/klemmenovv-maker/backup-info/issues). Don't include credentials or private photos in public issues.
