Privacy policy

Effective September 15, 2026. Backup is a personal macOS photo backup application maintained by GitHub user klemmenovv-maker.

Information accessed

Backup reads files and photo metadata from locations selected by the user. With Google authorization, it reads Google Drive file names, identifiers, sizes and checksums to find existing backups and uploads selected photos to the user’s Google Drive archive. Google Drive quota information is displayed in the application.

Use and storage

Files are transferred from the user’s Mac to their Google Drive. OAuth credentials, file indexes, checksums and operation reports are stored locally on the Mac. Backup does not operate a separate server that collects these files or credentials. The informational website does not receive the application’s backup data.

Sharing

Backup does not sell personal information, use it for advertising or send it to AI models. Google processes uploaded data under its own privacy policy. Backup’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

User control and deletion

The user controls file selection and may stop transfers. Optional deletion of local paired JPEG files occurs only after the corresponding RAW backup is verified. Users may revoke Backup’s access through their Google Account connections, remove local Backup configuration and reports, and delete stored files directly from Google Drive. Revoking access does not delete existing backups.

Contact

Contact the developer through GitHub issues. Do not include credentials or private photographs in public issues.
