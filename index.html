Backup

A personal macOS application for selecting photographs from local folders, SSDs and memory cards and backing them up to the user’s Google Drive.

Backup supports CR3, ARW and JPEG files, compares file checksums to detect existing copies, and provides transfer reports. Optional deletion of paired local JPEGs requires verification of the corresponding RAW backup.

The application runs locally on the owner’s Mac. This website provides application information only.
